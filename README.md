# Sub-Store 双跳节点脚本

将名称匹配 ACPS、ACSS、ACAS 的香港或新加坡节点作为入口，美国节点作为出口，生成双跳节点。仅处理节点，不包含订阅地址或凭据。

在 Sub-Store 的组合订阅中添加「脚本操作」，选择远程脚本并填入 `chain.js` 的 Raw 地址；预览后以 Shadowrocket 格式导入。输出保留前置节点，双跳节点名称以 `双跳-` 开头。现有订阅可保留用于回滚。

在 Shadowrocket 创建 fallback 代理分组，选择输出订阅并用 `^双跳-` 筛选；流量规则需指向该分组。订阅更新可在 Shadowrocket 中单独设置，脚本不能监听客户端超时并即时触发更新。后台更新受 iOS 调度限制。

链式代理是否生效取决于客户端版本、节点协议和服务商配置。导入后检查「代理通过」、测试连接及出口 IP；脚本未在实际订阅上端到端验证。名称中的高速不代表实测带宽。
