# Sub-Store 链式代理脚本

| 脚本 | 用途 | 固定远程地址 | 设置与实测 |
| --- | --- | --- | --- |
| `chain.js` | AI 专用双跳优选，新加坡主用及同区备用，美日韩候选 | https://mouss.synology.me:1050/chain.js | [AI.md](AI.md)、[SETUP.md](SETUP.md) |
| `chain-best.js` | 全地区双跳优选 | https://mouss.synology.me:1050/chain-best.js | [BEST.md](BEST.md) |

固定 URL 持续更新，不添加版本参数。脚本放在原始订阅处理的最后，入口保留并置底；不要重复处理链式输出，也不要在脚本后改名或删除入口。

AI 版节点名以 `双跳-AI` 开头，入口以 `入口-AI-` 开头，与全地区版区分；原 `^双跳-` 筛选兼容。两份脚本均不包含订阅凭据，实际连接参数来自输入订阅。

排序是实测快照，实时健康检查和故障切换由客户端处理。AI 版仅完成网络和未认证服务响应检查，不能据此承诺已登录可用、模型生成成功或长期稳定。ChatGPT 网页自动化检查遇到了 Cloudflare 校验。
